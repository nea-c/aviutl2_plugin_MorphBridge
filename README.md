# MorphBridge

前後に置いた2つのオブジェクトのシルエットをモーフィングするメディアオブジェクトを追加するAviUtl2用プラグイン

![sample](sample.webp)

## 最新 / Latest

**r1**

## 使い方

同レイヤーに、間を空けず次の順番で配置します。

```text
前オブジェクト → MorphBridge → 後オブジェクト
```

`進捗`を通常の移動設定で0から100へ動かします。

- `色`：出力するシルエットの色
- `前後オブジェクト補正`：位置、拡大率、回転、縦横比の調整
